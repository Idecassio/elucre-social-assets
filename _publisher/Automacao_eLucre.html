Automação de Social Media — eLucre

Criação de calendário · posts · aprovação no Discord · publicação no Instagram

1 Como funciona — o fluxo

Dia 1 do mês · 08:55 · automático
Cria o calendário do mês (esqueleto: dias úteis, pilares, tema dark/claro). Avisa no Discord pra planejar. O conteúdo criativo (temas, legendas e artes) é preenchido pelo Claude a seu pedido.
▼
Todo dia · 09:00 · automático
Prepara o post do dia (feed + story) e posta a prévia no Discord (canal MC-monitor) com o horário de publicação.
▼
09:00 → 13:00 · você
Janela de veto (aprovação por silêncio). Não fez nada = aprovado. Se não quiser um post, é só vetar antes das 13:00.
▼
13:00 · automático (checa a cada 15 min)
Publica no Instagram (@elucre.oficial): feed + stories. Grava o link e atualiza o dashboard sozinho (posts do mês + check "Postado no IG").

2 As etapas em detalhe

AUTOMÁTICO + CLAUDE

📅 Calendário

No dia 1, o sistema cria o esqueleto do mês (arquivo novo por mês — nunca sobrescreve o anterior). O Claude preenche os temas, legendas e gera os assets quando você pede “monta o calendário de [mês]”.
FEITO PELO CLAUDE

🎨 Posts (criativos)

Cada peça é desenhada seguindo o playbook da marca e sai sempre em feed (1080×1350) + story (1080×1920). O sistema converte para JPG e organiza nas pastas.
AUTOMÁTICO

💬 Discord

Todo dia às 09:00 a prévia do post vai pro canal MC-monitor pra você revisar. É o seu ponto de controle: aprovar (silêncio) ou vetar.
AUTOMÁTICO

📸 Instagram

No horário, se não houve veto, publica feed + stories no @elucre.oficial via API oficial da Meta e registra o link da publicação.
AUTOMÁTICO

📊 Dashboard

O painel de acompanhamento (dashboard.html) é gerado a partir das fontes vivas (calendário + histórico de publicações). A cada publicação ele se atualiza sozinho: os posts do mês aparecem e o que foi ao ar fica marcado como "Postado no IG" — sem preencher à mão.

4 Quem faz o quê

🤖 Automático

  • Criar o esqueleto do calendário (dia 1)
  • Postar a prévia no Discord (diário)
  • Publicar feed + stories no Instagram no horário
  • Registrar o link e atualizar o dashboard (posts + checks "Postado no IG")

🧑‍💻 Você / Claude

  • Claude: preencher o calendário e criar os criativos (feed+story)
  • Você: revisar no Discord e vetar o que não quiser

5 Como operar

🛑 Vetar o post do dia

Antes das 13:00, rode no terminal (na pasta _publisher):

node scripts/elucre/veto.mjs today

…ou peça ao Claude “veta o post de hoje”. O post não vai ao ar.

⏸️ Pausar / retomar tudo

Desligar a automação:

./scripts/elucre/schedule.ps1 -Remove

Religar:

./scripts/elucre/schedule.ps1

⚠️ Ponto de atenção: O agendador é local — o computador precisa estar ligado no horário da publicação (~13:00). Os tokens do Instagram e do GitHub não expiram.
Peças técnicas: motor em eLucre_Posts\_publisher (Node) · imagens hospedadas no GitHub (repo público) · publicação via Instagram Graph API (@elucre.oficial, conta própria) · fila/histórico em ledger.json · acompanhamento no dashboard.html (auto-gerado do calendário + ledger). Segredos ficam só no .env (nunca expostos). · Documento gerado em 28/09/2026.
