# inbox/ — imagens prontas para publicar

Coloque aqui os **JPGs prontos** (criados fora da skill: Canva, Figma, IA, etc.)
que você quer publicar ou agendar pela sessão.

- Formato: **JPG**, **1080×1350** (4:5), até 8 MB.
- Depois, diga ao Claude o caminho + legenda + horário. Ex.:
  *"Sobe a `inbox/promo-sexta.jpg`, legenda tal, agenda pras 21h."*

Os arquivos daqui não são versionados (só este README).
